# 魔法の球 バレー

線を描けば、それが魔球になる。「魔法の球」のバレーボール版。

- サーブ：ジャンプサーブ・ジャンプフローター・アンダーサーブから選び、打つ高さ・回転（無回転・ドライブ・左・右）・球速（30〜130km/h）を決めて、ボールから落ちる所まで線を描く。ネットをこえて、アンテナの内側を通り、相手のコートの中に落とす
- 回転はネットをこえたあとに効いてくる（無回転はゆれる、ドライブは落ちる、左右は曲がる）
- レシーブ：9m×9mのコートを走り回って受ける。画面のどこでも指を置いて動かすと走り（ぷにコン）、右下のボタンでフライング。ボールが体のどこかに当たればレシーブ成功
- 1本勝負。上げれば勝ち、エースなら負け。上げられていない魔球のランキング（今日・全期間）
